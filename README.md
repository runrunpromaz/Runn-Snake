# Runn Snake

English-language snake arcade PWA. No external dependencies.

## Publish on GitHub Pages
1. Create repository `runn-snake`.
2. Upload all files in this ZIP to repository root.
3. Settings > Pages > Deploy from branch > main / (root).
4. Visit `https://YOUR_USERNAME.github.io/runn-snake/`.
5. Enter the URL at https://www.pwabuilder.com/ to build a Windows package for Microsoft Store.

The ZIP is PWA source, **not** an MSIXBUNDLE. Review Publisher identity, signing, capabilities, and Microsoft Store certification requirements.
